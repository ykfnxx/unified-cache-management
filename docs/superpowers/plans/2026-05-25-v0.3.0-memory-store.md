# v0.3.0 MemoryStore Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `MemoryStore` module on top of `v0.3.0` that preserves `develop` `MemoryStore` semantics, keeps the standard `StoreV1` path compatible with `v0.3.0`, and exposes public per-token-per-layer APIs.

**Architecture:** Extend the shared type / `StoreV1` / binder / Python abstract layers first, then add a standalone `ucm/store/memory` module whose internal model matches `develop`: typed token chunks plus full-shard readiness, backend full-shard fallback, and queue-managed async load/dump stages modeled on `v0.3.0` `CacheStore`.

**Tech Stack:** C++17, pybind11, Python connectors, GoogleTest, existing `ucm/shared/trans` transfer streams and `Detail::TaskWrapper`.

```cpp
TEST(UCMMemoryStoreTest, TokenDumpLoadRoundTripUsesTensorType)
{
    auto store = std::make_unique<UC::MemoryStore::MemoryStore>();
    UC::MemoryStore::Config config;
    config.storeBackend = 0;
    config.deviceId = 0;
    config.shardSize = 16;
    config.blockSize = 16;
    config.tensorSizeList = {8, 8};
    config.memoryTokenChunkSize = 2;
    config.memoryBufferCapacity = 1ULL << 20;
    config.requiredTensorTypes = {0, 1};
    config.tensorSizesByType = {{0, {4}}, {1, {4}}};
    ASSERT_EQ(store->Setup(config), UC::Status::OK());

    auto block = MakeBlockId(7);
    std::array<std::byte, 4> src{std::byte{1}, std::byte{2}, std::byte{3}, std::byte{4}};
    std::array<std::byte, 4> dst{};
    UC::Detail::TokenLayerTaskDesc dump;
    dump.push_back({block, 0, 0, 0, {src.data()}});
    auto dumpTask = store->DumpTokens(dump);
    ASSERT_TRUE(dumpTask.HasValue());
    ASSERT_EQ(store->Wait(dumpTask.Value()), UC::Status::OK());

    UC::Detail::TokenLayerTaskDesc query;
    query.push_back({block, 0, 0, 0, {dst.data()}});
    ASSERT_EQ(store->LookupTokens(query).Value(), std::vector<uint8_t>{1});
    auto loadTask = store->LoadTokens(query);
    ASSERT_TRUE(loadTask.HasValue());
    ASSERT_EQ(store->Wait(loadTask.Value()), UC::Status::OK());
    EXPECT_EQ(std::memcmp(src.data(), dst.data(), src.size()), 0);
}
```

- [ ] **Step 3: Port the queue/task machinery from `develop` but keep it local to `MemoryStore` and v0.3.0 conventions**

```cpp
class TransTask {
public:
    enum class Type : uint8_t { LOAD, DUMP, LOAD_TOKENS, DUMP_TOKENS };
    Detail::TaskHandle id{0};
    Detail::TaskDesc desc;
    Detail::TokenLayerTaskDesc tokenDesc;
};
```

```cpp
class TransManager : public Detail::TaskWrapper<TransTask, Detail::TaskHandle> {
    LoadQueue loadQ_;
    DumpQueue dumpQ_;
};
```

Key staging rules:
- `LoadQueue`: dispatch reads local-full/token hits; backend misses become async backend `Load` submission; transfer stage performs backend `Wait`, local commit, then `Trans::Stream::HostToDeviceAsync`
- `DumpQueue`: dispatch waits on optional prerequisite handle, performs `Trans::Stream::DeviceToHostAsync`, commits host data into local chunk/full state, submits backend `Dump`; later backend stage performs backend `Wait`
- use `ucm/shared/trans` public APIs directly; do not add new D2H wrappers
- do not hide backend `Wait` inside `TransBuffer`
